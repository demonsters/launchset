`launchset ship --attempt <n>` sets the last two digits of a `semver` build number (1 to 99), so a second upload of the same version gets a number the store doesn't have yet. Before, a hand-made build always got attempt 1. Shipping from CI takes the same value: the release workflow's new `attempt` input, or `LAUNCHSET_ATTEMPT` on GitLab. It is an error for a target with another strategy, and without a target. A `launchset-release.yml` generated by an earlier version has no `attempt` input: add it next to `force` as a `string` input (see Build numbers in the docs).
